# Consignes locales — Advanced Project

## Publication GitHub

- Toute modification doit passer par une branche dédiée et une pull request, y compris une annulation ou une correction documentaire.
- Ne jamais pousser directement sur la branche par défaut ni sur une autre branche protégée, même lorsqu'une demande mentionne simplement « commit et push ».
- Utiliser le préfixe `fix/` pour les branches correctives, sauf demande explicite contraire.
- Une demande de publication autorise le push de la branche et l'ouverture de sa PR ; elle n'autorise pas sa fusion. Ne fusionner qu'après instruction explicite.
- Vérifier le diff complet par rapport à la base et le SHA publié ; ne pas réécrire l'historique pour réparer un push direct.

Ces consignes complètent le référentiel global Dolibarr sans en recopier les règles métier.
